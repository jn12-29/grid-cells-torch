# Repo Notes

- Project maintenance notes, workflow contracts, and local development caveats live in `docs/maintenance.md`.
- Documentation should not restate default values that are directly visible in `config.yaml`; mention field names, behavior, and non-obvious consequences instead.
- `model.bottleneck_post_activation` controls the model-side transform after bottleneck linear and before dropout/output heads. Statistical-analysis module toggles live under `analysis.compute_*`, including grid selectivity, Banino-style grid geometry, and the optional `analysis.compute_linear_spatial_pca` v1 baseline. Eval rate-map/grid-score and statistical-analysis consumers use `analysis.bottleneck_activation`; `raw` uses the model-returned bottleneck without an extra eval transform. Disabled per-unit modules preserve `eval_stats` artifact fields with `NaN` or `false` placeholders, and grid-scale summaries expose all-unit, `grid_fdr_*`, and `grid_threshold_*` variants with discreteness shuffle significance, GMM/BIC scale-cluster fitting, and population scale histogram/GMM overlay plots. Linear spatial-PCA artifacts use the separate `linear_spatial_pca_*` prefix, include optional overview/mode-map diagnostics controlled by `analysis.linear_spatial_pca_save_plots` and `analysis.linear_spatial_pca_plot_top_n`, and are not grid-score-optimized `W` searches.
- Training optimizers are selected with `training.optimizer`; supported values are `rmsprop`, `adamw`, `adam`, `sgd`, and `lion`. `training.betas` applies to Adam, AdamW, and Lion when set; `training.adamw_eps` applies to Adam and AdamW; `training.momentum` applies to RMSprop and SGD.
- `analyze_checkpoint.py --checkpoint <path>` reloads schema-v1 checkpoint weights for post-hoc full eval/analysis and writes to `<run directory>/ckpt_analysis/<checkpoint_stem>/` by default; this is not training resume.
- Gradient processing is controlled by `training.grad_processing_mode`; `clip` uses `training.grad_clip_mode` (`value` or `norm`), and `sign_mean_abs` replaces selected gradients with signed per-parameter mean magnitudes while zeroing entries with `abs(grad) <= training.grad_clip`. `training.grad_clip_scope` selects `decoder` or `all`; `training.grad_clip_norm_type: "inf"` rescales selected gradients by the largest absolute gradient value in `clip`/`norm` mode.
- Training logs sampled per-module gradient diagnostics for `state_init`, `cell_init`, `lstm`, `bottleneck`, `pc_heads`, and `hdc_heads`; TensorBoard step/epoch-mean tags live under `train/grad/<module>/...` for norm, RMS, mean-absolute, signed-mean, max-absolute, `pre_clip_exceed_frac` (`abs(grad) > abs(training.grad_clip)` before processing), `clip_changed_frac`, `post_clip_saturated_frac`, and `clip_ratio`, and `train.log` includes compact epoch sampled means.
- `training.first_pos_loss_multiplier` controls timestep-0 PC target-loss weighting without adding a decoded-MSE auxiliary loss.
- Training and evaluation logs include whole-sequence `pos_mse` / `hd_mae_rad` plus first-step `first_pos_mse` / `first_hd_mae_rad`; the first-step target is `target_pos[:, 0]` / `target_hd[:, 0]`, not raw `init_pos` / `init_hd`.
